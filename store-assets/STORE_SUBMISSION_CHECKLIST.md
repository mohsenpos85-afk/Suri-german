# Store Submission Checklist

## Technisch
- [x] Capacitor Android/iOS Projekte vorhanden
- [x] Android targetSdk 36, minSdk 24
- [x] Android Debug-APK baut erfolgreich
- [x] Android Release-AAB baut erfolgreich
- [x] Native Kamera, Dateiauswahl, Zurück-Taste und Safe Areas integriert
- [x] Lint, Tests, Übersetzungschecks und Production Build automatisiert
- [x] Optionale Crash-Erfassung vorbereitet (`VITE_SENTRY_DSN`)
- [x] App-Icon und Splash für Android/iOS erstellt
- [x] Google-Play-Icon und Feature Graphic erstellt
- [ ] Eigenen Release-Signing-Key sicher erstellen und Android App Bundle für Google Play signieren
- [ ] iOS auf macOS/Xcode archivieren und signieren

## Recht/Datenschutz
- [x] Öffentliche Kontolöschungsanleitung vorhanden
- [x] Data-Safety/App-Privacy-Arbeitsentwurf vorhanden
- [ ] Echter Name/Firma, ladungsfähige Adresse und Kontakt-E-Mail einsetzen
- [ ] Datenschutzerklärung und Impressum anwaltlich prüfen
- [ ] Supabase/Anthropic/Sentry DPA, Region und Aufbewahrung bestätigen

## Store-Konten und Tests
- [ ] Google Play Console App anlegen
- [ ] Android Internal Test hochladen und Geräteprüfung durchführen
- [ ] Apple Developer Account/App Store Connect App anlegen
- [ ] TestFlight-Build von einem Mac hochladen
- [ ] Screenshots auf echten Zielgeräten erstellen
- [ ] Data Safety und App Privacy im jeweiligen Portal absenden
- [ ] Altersfreigabe, Content Rating und Export Compliance beantworten
- [ ] Production Release nach bestandener Beta freigeben
